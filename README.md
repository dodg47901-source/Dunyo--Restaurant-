DUNYO — демонстрационный сайт ресторана

Файл index.html — готовая статическая страница.
Перед публикацией проверьте актуальность контактов, меню и цен, а также замените демонстрационные фотографии на разрешённые фотографии ресторана.

Публикация через GitHub Pages:
1. Войдите в GitHub и создайте новый публичный репозиторий, например dunyo-restaurant.
2. Добавьте в репозиторий файл index.html из этой папки.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. Подождите несколько минут и откройте адрес сайта, который покажет GitHub Pages.
